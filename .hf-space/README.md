# NetPulse Network Monitor

Real network measurements from the NetPulse API. Configure the public backend URL as the `NETPULSE_API_URL` Space variable. The dashboard is read-only and uses only explicitly configured demo targets. The static frontend assets are generated from `frontend/` and committed at the Space root for reliable, no-compute hosting.
